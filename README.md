# Сайт школы ИЗГИ

Публичный сайт + кабинет сотрудников + панель директора.
Сайт — статические файлы (GitHub Pages). Серверная часть — Supabase Edge Function `supabase/functions/api/index.ts`,
данные лежат в таблице `kv` (см. `supabase.sql`). Пароли хранятся только как хэш.

## Настройка (один раз)
1. Supabase → SQL Editor: выполнить `supabase.sql` (создаёт таблицу).
2. Supabase → Edge Functions → создать функцию `api`, вставить код из `supabase/functions/api/index.ts`,
   в настройках функции выключить «Verify JWT» и нажать Deploy.
3. Edge Functions → Secrets: добавить `AUTH_SECRET` (случайная строка от 32 символов), `DIRECTOR_LOGIN`, `DIRECTOR_PASSWORD`
   (и при желании `DIRECTOR_NAME`).
4. GitHub: репозиторий → Settings → Pages → Deploy from a branch → `main` / `(root)`.
5. Открыть адрес сайта, `/staff.html`, войти как директор и создать сотрудников.

Адрес функции записан в `js/config.js`. Директор создаётся автоматически при первом входе.

## Права доступа
- **Директор** — владелец: его нельзя удалить, лишить прав или сменить ему пароль другим аккаунтам.
- **Полный доступ** — те же возможности, что у директора (кроме действий над аккаунтом владельца).
- **Ограниченные** — свои задачи и своё фото. Дополнительно можно выдать галочки: «Задачи сотрудников», «Аккаунты сотрудников», «Контент сайта».
- Директор и сотрудники с полным доступом меняют имя, должность, логин, пароль, фото и права любого аккаунта кнопкой «Изменить».
- Все проверки выполняет сервер (`supabase/functions/api/index.ts`). После смены логина или пароля старые сессии этого аккаунта закрываются.
После изменения `index.ts` его нужно заново вставить в Supabase (Edge Functions → api → Code) и нажать Deploy.

## Push-уведомления
- Сотрудник нажимает «Включить уведомления о задачах» в своём кабинете, браузер просит разрешение.
- Когда директор (или сотрудник с правом «Задачи сотрудников») назначает задачу, на подписанные устройства сотрудника приходит уведомление; нажатие открывает кабинет.
- Android (Chrome) работает сразу. На iPhone нужен iOS 16.4+ и сайт, добавленный на экран «Домой».
- Ключи VAPID сервер создаёт сам при первом запросе и хранит в таблице `kv` (ключ `vapid`), вводить их вручную не нужно.
- При выходе из аккаунта устройство отвязывается от него, чужие уведомления не придут.
